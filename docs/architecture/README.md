# docs/architecture — 架构决策记录 (ADR)

本目录存放 ODPlatform 项目的**架构决策记录**（Architecture Decision Records）。

每份 ADR 记录一次重要的架构决策：
- 为什么做这个决定
- 当时考虑了哪些替代方案
- 决定带来了什么后果（正面/负面/中性）
- 什么条件下应该重新考虑这个决定
